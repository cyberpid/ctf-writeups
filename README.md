# CTF White-ups & Cybersecurity Research

Welcome to the Cyberpid cybersecurity learning portfolio!

This repository is a growing collection of capture-the-flag write-ups, organized by platform. Each entry focuses on the *reasoning* behind the solve — why a tool, why a pivot, what the output revealed — not just the commands that happened to work.

Flags, challenge answers, and other sensitive details are dedacted to preserve the challenge experience for other learners.


## Disclaimer
These materials are intended for educational purposes and authorized security testing only. All content is shared in accordance with the applicable platform rules. Flags are redacted

## Structure

```
ctf-writeups/
├── README.md              # this index
└── <platform>/
    └── <challenge-slug>/
        └── README.md      # the write-up (renders automatically on GitHub)
        └── assets/        # screenshots, artifacts (optional)
```

Each challenge lives in its own folder so GitHub renders its `README.md` when you browse to it, and screenshots or files stay scoped to the challenge they belong to.
